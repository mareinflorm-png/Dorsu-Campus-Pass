# DOrSU Digital Campus Pass

A React Native + Expo app built for the DOrSU laboratory exercise on mobile UI fundamentals.

## Features
- Student profile card with status badge
- Gate scan counter with increment and reset actions
- Pass suspension toggle
- Peer props demo
- Responsive layout with Flexbox and StyleSheet

## Run locally
```bash
npm install
npx expo start
```

## Notes
- Use Expo Go on a mobile device or an emulator.
- The project follows the DOrSU Digital Campus Pass laboratory instructions.
